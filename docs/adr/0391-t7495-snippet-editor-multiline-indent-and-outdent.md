# ADR 0391：代码片段实验室编辑器多行 Tab 缩进与 Shift+Tab 反向退格加固（T-7495）

## 状态

已采纳 (Accepted) - 2026-10-29

## 背景

代码片段实验室（Snippet Studio）内置轻量级代码编辑器。此前：
1. `Tab` 键仅支持单光标位置插入 2 个空格，当选中多行代码时按下 `Tab` 会将整段选区替换为 2 个空格，与专业代码编辑器（如 VS Code）的多行块缩进预期不符；
2. 缺乏反向缩进（Outdent / Dedent）：当用户按下 `Shift+Tab` 时未做反向退格处理，无法快速整理层级。

## 决策

1. **多行选区批量正向与反向缩进**：
   - 在 `src/snippet-studio-ui.js` 的 `editor` 监听中，精确识别选区跨行场景（`start !== end && val.substring(start, end).includes("\n")`）；
   - 正向 `Tab`：为选区包含的每一行行首统一增加 2 个空格，并按行数平滑递增 `selectionEnd`；
   - 反向 `Shift+Tab`：逐行剔除行首至多 2 个前导空格（或 1 个制表符），并动态计算第一行与整体缩减量，精确保全选区位置。

2. **单行光标 Shift+Tab 退格当前行**：
   - 当单光标或单行选区下按下 `Shift+Tab` 时，向前检测当前行行首，若存在前导空格则剔除至多 2 个并回拉光标，操作体验与主流 IDE 保持高度一致。

## 验证

- **契约测试**：`tests/snippet-editor-multiline-indent.test.cjs` 2/2 满分通过，验证多行判定、行首裁剪、选区保持与单行反向退格；
- **负向验证**：修改选区计算变量断言注入故障，确认测试精准拦截，还原后通过。
