# ADR 0537: 第一面板全高网格延伸、工作台柔彩Bento调色与片段灵感商店优化（T-7829）

## 状态
已决断并实施 (Accepted)

## 背景与问题核实（图1～图5）
1. **图1（第一面板预览延伸）**：
   - 现场测算发现：`.sw__tab-preview.sw--with-preview` 原网格行高未声明 `grid-template-rows: 1fr`，导致网格行高度被左侧卡片内容高度（`auto`）约束在约 940px，高分屏（1600px 高度）大窗下右侧预览窗格随之停止在 y=1220，留出 300px 巨大空白。
2. **图2（第二面板部分插件内容显示不正常）**：
   - 工作台中的“渐进知识蒸馏漏斗”与“今日任务视界”属于外部插件桥接组件（依赖小驴拾遗与 Task Horizon）；在未安装这些生态插件的纯净工作区中，桥接接口返回 0 或“未检测到插件”空态。
3. **图3（第二面板部分插件颜色无法改变、太黑）**：
   - `src/index.ts` 原默认配置把 `homePalette` 设为 `"soft"`，而 `second-panel-ui.ts` 仅在 `homePalette === "auto"` 时注入 `--sw-home-accent`，且样式未给普通卡片注入柔彩渐变，导致大多数小组件退化为沉闷死黑的纯暗色底。
4. **图4（第二面板小组件商店重构思考）**：
   - 商店平铺 72 个小组件，分类扁平、说明冗长，缺乏视觉分组与一键“添加/移除”直观对比。
5. **图5（第三面板片段商店优化）**：
   - “片段商店”入口隐蔽地挤在代码编辑器工具栏中间一排 12 个小图标里；左侧目录仅展示当前已装片段，用户感知“内容太少、入口太不明显”。

## 决策与实现
19	1. **第一面板三部分布局与预览满高延伸（T-7829 & T-7830）**：
   - **根本原因**：切换器 DOM 结构中原有一个全宽度的 `.sw__workbench-dock`（即“当前文档相关”横栏）横亘在 `.sw__scroll` 视口下方，占据了底部 152px，导致其内部右栏的预览窗格物理上无法越过该底栏延伸到底部；
   - **三分区架构落地（对齐用户图2）**：在双栏预览模式下，将底栏从全宽结构中剥离移入左栏（`.sw__tab-content`）底部，从而彻底释放右侧整列。左上为页签缩略图卡片，左下为轻量工作台/快捷内容，右侧为纵贯全高的独立文档速览窗格（实测由 1145px 延伸至 **1297px / 1329px**，紧贴最底栏，彻底消除断层）；
   - **“当前文档相关”解析**：该栏目为当前文档的反链与提及（Backlinks & Mentions），因普通文档反链较少易出现重复标签，已提供左栏自适应与收起方案。
20	2. **工作台外部桥接组件优雅回退（T-7829）**：
21	   - 在 `src/home-external-adapters.ts` 中针对未安装对应插件的环境，将 `knowledge-funnel` 与 `task-horizon-today` 改造为友好清晰的“生态联动”引导条目，杜绝突兀的 0 篇或报错态。
22	3. **工作台多彩 Bento 配色与现场 🎨 变色入口（T-7829）**：
23	   - 在 `src/second-panel-ui.ts` 中激活全量 `--sw-home-accent` 散列与用户自定义 `inst.config.accent`；
24	   - 在 `_05-settings-widgets.scss` 中为 `.sw-home__cell` 注入基于 `--sw-home-accent` 的轻盈 Bento 径向/线性双层微光底色与精致微光边框；
25	   - 在编辑布局工具条中新增 **`🎨 变色`** 工具，点击即可在 8 种高雅 iPad 强调色（薰衣草紫、海蓝、薄荷绿、蜜糖金、玫瑰粉等）中即时轮换并保存。
26	4. **工作台小组件商店重构路线（T-7829）**：
27	   - 确立“常用精选 / 笔记沉淀 / 习惯时间 / 资讯灵感 / 生态扩展” 5 维层级重构路线，收敛冗余假源。
28	5. **片段实验室【✨ 预设商店】显式入口与 26+ 预设激活（T-7829）**：
29	   - 在片段目录顶栏显式外置 **`✨ 预设商店`** 柔彩胶囊按钮，一键直达完整预设库；
30	   - 激活内置的 26+ 款高品质思源 CSS 视觉美化片段（彩色引述、并排双栏、代码块圆点、表格斑马纹等）。
