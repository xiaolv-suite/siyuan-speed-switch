# 0293. T-7396 Webpack 压缩参数调优与发布包体预算余量拓展契约

- **状态**：accepted
- **日期**：2026-10-27
- **任务**：T-7396

## 背景与上下文

小驴雷切发布包维持 660 KiB（675,840 字节）的严格发布门禁。在近期引入 256×256 殿堂级头像（65,989 B）以及多批生态与交互增强（⌘K 动作画板批量关闭、活跃文档上下文自适应透传、思源块定位滚动与拦截、小组件商店全键盘流、漫游动作与知识漏斗）后，工作树 `package.zip` 达到 672,884 字节，距离 660 KiB 门限仅余 2,956 字节（0.43%）。

为了在不破坏代码可读性与可维护性的前提下，为后续迭代拓展安全的包体呼吸空间，需对构建管线进行专项优化。

## 架构决策

1. **构建压缩管线深化优化**：
   - 在 `webpack.config.js` 的 `TerserPlugin` 中开启深层优化参数：
     - `compress.passes: 3`：执行多阶段死代码消除与冗余常量折叠；
     - `compress.pure_getters: true`：优化属性访问；
   - 优化后生产构建产物：
     - `dist/index.js`：从 1,265,208 字节下降至 **1,261,649 字节**（净减 3,559 字节）；
     - `package.zip`：从 672,884 字节下降至 **671,598 字节**（净减 1,286 字节）；
     - 距离 660 KiB 门限的余量从 2,956 字节拓展至 **4,242 字节**。
2. **可复现构建保证**：
   - 多轮生产构建通过 `pnpm repro:audit` 校验，输出 3/3 文件散列与字节数 100% 绝对一致；
   - 保持发布包文件修改时间归一化（`RELEASE_ZIP_MTIME`）。
3. **门禁与测试**：
   - 新增 `tests/bundle-optimization-and-headroom-contract.test.cjs`；
   - 负向验证：若 Terser passes 参数被意外还原或产物超出 660 KiB 门禁，断言必须精准红。

## 后果与影响

- 成功为后续版本迭代拓展了宝贵的包体预算安全空间；
- 生产构建产物具备更高的执行效率与更小的网络传输/磁盘占用。
