# 架构决策记录 0493：T-7650~T-7653 切换器视口 8px 安全缓冲、实验室手风琴折叠交互与工作台防跳变闭环

## 一、 背景与动因

在持续深化的视觉与交互体验打磨中，发现了以下两处微观体验断点：
1. **视口滚动贴边压盖**：切换器中通过键盘上下方向键滚动列表时，原先计算仅按卡片边框与容器边框的零距离减法滚动，导致选中的卡片紧紧顶在容器最顶端或最底端，甚至被顶栏的柔和投影遮盖一部分，缺乏呼吸感；
2. **实验室 AI 伴侣收起易用性**：AI 栏折叠为 48px 极窄竖条时，由于按钮微小且周围缺乏明确点击区，用户若想重新展开操作困难；
3. **工作台小组件骨架渲染防抖**：首屏加载时骨架屏到真实内容切换偶发触发外层容器重排。

---

## 二、 架构决策与标准落地

### 1. T-7650 滚动视口 8px 舒适缓冲留白（A 档）
- `src/index.ts` 与 `src/index.js` 的 `scrollIntoView` 中，加入 8px 缓冲量（`const cushion = 8;`）：
  - 向上回卷时保持顶部保留 8px 间距，不被顶栏投影遮挡；
  - 向下滚动时保持底部保留 8px 间距，提升视觉从容度。

### 2. T-7651 片段实验室手风琴折叠手势强化（A 档）
- `src/styles/_snippet-studio.scss`：折叠态声明 `cursor: pointer;` 与 `:hover` 主题色淡底微提亮，点击整个 48px 纵向细条即可一键展开；
- 折叠切换微按钮补齐 28px 规范圆角与悬停反馈。

### 3. T-7652 第二面板主滚动区隔离渲染防抖（A 档）
- `.sw-home__body` 显式注入 `contain: layout paint`，将网格渲染范围隔离在滚动视口内部，杜绝首屏骨架屏拔插时的全局回流。

### 4. T-7653 契约测试与破坏性负向探针验证
- 新增专项测试 `tests/staggered-viewport-and-studio-accordion-contract.test.cjs`；
- 破坏性负向探针验证滚动缓冲被清零或手风琴触控缺失时报警退出。
