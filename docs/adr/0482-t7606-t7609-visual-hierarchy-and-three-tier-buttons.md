## 一、 背景与动因

在完成 T-7605 基础令牌与内阴影/拟物渐变清除后，界面仍面临跨窗口组件主次不分明、按钮体系缺乏明确层级、交互状态反馈不完整等细节问题：
1. **第一面板视觉层级堆叠**：药丸栏与结果卡片行存在多余的局部内边框和伪元素白条，高分屏下容易造成视觉疲劳；
2. **按钮跨表面不一致**：切换器、工作台、设置弹窗和实验室等多个窗口中，同等语义的按钮形状与边框各异，未严格收敛至三级模型；
3. **缺少物理按下态微触感**：部分次级操作和静默操作缺少 `:active` 时的 `scale(0.985)` 与微下沉反馈；
4. **键盘焦点感知割裂**：个别操作按钮在键盘导航时仅显示粗糙的 outline，未接入统一的双层发光环 `--sw-focus-glow`。

---

## 二、 架构决策与标准落地

### 1. T-7606 切换器第一面板视觉层级精修（A 档）
- 彻底移除卡片与列表行中残存的字面阴影（`0 1px 2px rgba(0, 0, 0, 0.03)`）与内凹亮边（`inset 0 1px 0 ...`）；
- 全面收敛至 `--sw-shadow-xs`（常态）与 `--sw-shadow-sm`（悬停/激活），以 8px/12px 留白替代多重实线边框；
- 药丸栏选中态切换至中性抬升面，移除局部内阴影。

### 2. T-7607 三级按钮标准体系（A 档）
在 `_01-base-controls.scss` 中正式固化三级按钮模型，跨窗口完全统一：
- **Primary 一级主动作** (`.sw-btn--primary`)：主色胶囊底（`--sw-color-accent`）+ 反白文字 + 统一 `:hover` 微浮起与 `:active` 微缩放；
- **Soft 二级次级胶囊** (`.sw-btn--soft`)：12% 主色淡底（`--sw-color-accent-soft`）+ 主色文字；
- **Quiet 三级静默操作** (`.sw-btn--quiet`)：透明底 + 文本色，悬停时产生中性沉底面（`--sw-color-surface-muted`）。

### 3. T-7608 控件八态全生命周期微交互（A 档）
- **八态规范**：默认（平整哑光）、悬停（微提亮+浮起）、按下（微下沉+缩放 0.985）、聚焦（`--sw-focus-glow` 双层发光环）、选中（主色边框+淡底）、禁用（`opacity: 0.42` + `cursor: not-allowed`）、加载中（等宽骨架/旋转圈）、空/错（人类可读+语义色彩）；
- 杜绝粗暴大位移与无意义弹跳，交互响应零延迟。

### 4. T-7609 契约测试与负向验证（Negative Verification Probe）
- 新增专项测试 `tests/visual-hierarchy-and-three-tier-buttons-contract.test.cjs`；
- 包含物理缩放位移篡改探针与破坏性自检，负向测试精准报警，确保规范长期不可逆回归。
