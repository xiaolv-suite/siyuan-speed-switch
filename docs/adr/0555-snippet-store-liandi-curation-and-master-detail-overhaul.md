# ADR 0555: 片段商店链滴社区名作置顶与 Master-Detail 黄金交互重构（T-7867）

## 状态
已决断并实施 (Accepted)

## 背景与问题诊断
针对用户反馈：“片段商店之前加入了很多链滴社区的内容，怎么不见了？而且整个商店都不好。很多UI也有问题。位置摆放也不合理。很多变化也很大。你整体的再梳理下。另外主要另外一个对话也在开发。”，进行了系统级的代码与用户截图（截图 0～6）审查，确认了以下四大根本缺陷：

1. **梯队混排导致链滴社区名作沉底被淹没**：
   - 片段商店把用户本地已有的 11 款原生片段（`native`）混入商品池，且底层排序默认优先排列原生片段，导致一打开商店，满屏全是本地未整理草稿，精心收录且完成现代思源适配的 10 款链滴社区名作被挤出首屏；
2. **“社区目录尚未建立”消极占位文案误导**：
   - 预览详情面板默认显示早期留存的废弃提示文案，导致用户误认为社区内容被删除或未上线；
3. **顶栏重复堆叠与垂直高度严重挤压**：
   - 商店顶栏同时挂载了搜索框、4 个技术性 `<select>` 下拉框（全部分类、排序方式等），其正下方又平铺了 17 个分类胶囊，折成 2~3 行，占用近 200px 高度，且本地分组工具栏（分组视图/平铺/新建分组）依然露出；
4. **右侧详情主操作被埋在最底部**：
   - 右侧详情面板将「⚡ 一键安装并启用」按钮埋在沙箱 iframe 和 CSS 代码框下方，用户选中心仪样式后必须往后翻滚才能安装，且中间夹带对普通用户无意义的 diff 技术摘要（`0 个变动块 · +12 行 · -0 行`）。

## 决策与实施（T-7867）
1. **确立四级展示权重梯队（社区名作稳居首位）**：
   - 商店模式（`browse === true`）下按权重严密排序：
     - **第 0 梯队（置顶）**：10 款链滴社区精选名作（`isCommunity: true`），由社区作者（@Vanessa, @roy, @88250, @Zuoqiu-Ruozhi 等）署名并经过新版思源适配；
     - **第 1 梯队**：15 款官方高颜值精选预设（`featured: true`）；
     - **第 2 梯队**：本机已装片段（清晰标明“本机片段”，移除 35 字长句废话）；
     - **第 3 梯队**：基础内置预设；
2. **新增『🔥 链滴社区 · 10』专属直达胶囊与单行滑轨**：
   - 顶部分类胶囊首显位常驻 `🔥 链滴社区 · 10` 专属高亮胶囊，一键聚焦社区名作；
   - 胶囊栏重构为单行横向平滑滚动（`flex-wrap: nowrap; overflow-x: auto`），高度由 80px 骤减为 32px；
   - 商店模式隐藏重复的 `<select>` 分类与排序下拉框，且强力隐藏本地分组管理栏；
3. **右侧详情台重整（黄金操作与原帖直达置顶）**：
   - 从上至下重排视觉重心：商品标题卡（带原帖直达按钮 `🌐 链滴社区原帖与讨论 · ld246.com ↗`） → **「⚡ 一键安装并启用」主操作按钮** → 沙箱实时预览舞台 → 源码透视卡；
   - 彻底隐藏 diff 变动行数技术噪音；
4. **小组件商店详情面板黄金操作置顶与穿透消除**：
   - 将 `.sw-home-store__detail-actions` 调整为 `order: 2; position: static;`，置顶于实时沙箱预览上方，彻底根除因半透吸底导致的文字乱码重叠 Bug；详情头部屏蔽误导性的「条件可用」警告标签；
5. **并发开发安全防线**：
   - 严格约束改动范围在双商店与实验室相关文件；绝对不破坏或改动其他对话可能涉及的模块。
