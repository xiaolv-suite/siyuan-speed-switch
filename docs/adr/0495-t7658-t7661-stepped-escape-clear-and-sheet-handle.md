## 一、 背景与动因

在搜索交互流与移动端触控体验审计中，发现了以下两处微体验短板：
1. **搜索框 Escape 一刀切清空丢失前缀**：在多模态检索中（如 `@大纲 需求规范` 或 `task:今日工作`），原逻辑单按 Escape 会将整行连同模式前缀一并置空，用户若想在同一模式下换词检索，必须重新键入前缀或重新点击药丸，操作链被打断；
2. **移动端弹窗顶部缺乏手势视觉暗示**：移动端切换器 Sheet 顶部虽然支持滑动关闭，但在视觉上缺乏标准底部页（Bottom Sheet）的胶囊拖拽手柄，用户难以建立明确的手势预期。

---

## 二、 架构决策与标准落地

### 1. T-7658 搜索框两阶梯 Escape 智能回退（A 档）
- `src/index.ts` 与 `src/index.js` 中的 `bindSearchInputComposition` 升级为两阶梯清空：
  - **第 1 阶**：若输入框包含符号前缀且附带查询词，按下 Escape 优先截断查询词，保留前缀（如保留 `@` 或 `task:`）；
  - **第 2 阶**：当输入框仅剩前缀或为普通纯文本时，再次按下 Escape 清空整行并退回“全部/页签”全量模式；
  - **第 3 阶**：当完全为空时，不拦截事件，冒泡至宿主窗口执行优雅关闭。

### 2. T-7659 移动端 Sheet 顶部胶囊微手柄（A 档）
- 在 `src/styles/_03-switcher-mobile.scss` 的 `&.sw__mobile::before` 中，注入 36×4px 胶囊拖拽指示条，提供明确的手势视觉锚点，圆角收敛至 999px 胶囊。

### 3. T-7660 工作台场景预设菜单与回执状态同步（A 档）
- 保持场景预设应用与持久化、撤销历史记录和底部回执条的一致性流转。

### 4. T-7661 契约测试与破坏性负向探针验证
- 新增专项测试 `tests/stepped-escape-clear-and-sheet-handle-contract.test.cjs`；
- 破坏性负向探针验证阶梯回退若被破坏直接清空时报警退出。
