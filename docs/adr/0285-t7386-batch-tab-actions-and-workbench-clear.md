# ADR 0285：T-7386 批量页签管理矩阵、右键菜单扩展、工作台清空确认与 v0.48.28 闭环

日期：2026-10-27  
状态：accepted  
任务：T-7386  

## 背景

在多端日常深度使用中，用户普遍面临两大操作效率瓶颈：
1. **大量已打开页签缺乏高效的批量整理机制**：
   - 当打开二三十个文档后，只能逐张卡片点击叉号关闭；
   - 缺少现代浏览器级别的“关闭其他页签”、“关闭其后/下方页签”以及“保留置顶、关闭所有临时文档（关闭未置顶）”能力；
2. **第二面板（工作台）布局编辑缺乏全量清空与防误触确认**：
   - 用户尝试探索全新场景或快速整理桌面时，只能逐个点击卡片工具栏的“移除”；
   - 缺少一键清空全部组件能力，且一旦操作必须具备明确的二次防误触对话框与可逆的撤销历史保护。

## 决策

1. **动作画板（⌘K）扩展三大高能批量关闭动作**：
   - `close-other-tabs`（“关闭其他页签”，快捷键 `⌥⌘T`）：保留当前页签，安全批量关闭其余已打开文档；
   - `close-tabs-after`（“关闭右侧/下方页签”，快捷键 `⌥⌘→`）：关闭当前文档之后排列的所有页签；
   - `close-unpinned-tabs`（“关闭未置顶页签”，快捷键 `⌥⌘U`）：保留所有图钉置顶的核心文档，一键清理所有临时会话；
   - 批量关闭全部接入可撤销历史（`undoLastClosedTab`），随时支持误操作一键找回；
2. **卡片右键菜单（Context Menu）同步扩展**：
   - 鼠标右键直接提供“关闭其他页签”、“关闭其后页签”、“关闭未置顶页签”，无需呼出键盘即可快速整理；
3. **工作台编辑态增设“清空全部”与防误触弹窗**：
   - 工作台编辑工具栏新增 `sw-home__clear-btn`（清空全部）；
   - 点击弹出二次确认对话框，确认后清空布局并压入 `layoutHistory` 事务，支持一键 `Undo` 完整撤销恢复；
4. **版本号晋级（v0.48.28）**：
   - 全表面所有弹窗标题栏、中英文文档、更新日志与散列快照统一升级至 `v0.48.28`。
