# 0333. T-7436 多模态搜索模式 Chips 栏接入「待办模式」契约

- **状态**：accepted
- **日期**：2026-10-28
- **任务**：T-7436

## 背景与上下文

在切换器与移动端的常驻多模态搜索模式 Chips 药丸栏（`sw__mode-chips-bar`）中，此前支持大纲（`@`）、正文块（`^`）、标签（`#`）、书签（`!`）、命令（`>`）与速查（`?`）。
为了让用户能够一键切换至待办任务筛选态，并对齐 Issue #17 中关于支持 `task:` 或待办前缀快速检索的建议，雷切需在多模态药丸栏中正式接入待办模式。

## 架构决策

1. **待办模式药丸注册与前缀绑定**：
   - 在 `setupSearchModeChips` 的模式定义中增加：
     - `{key: "task", prefix: "-", label: "- 待办", icon: "iconCheck", placeholder: "- 待办…"}`。
2. **多源待办前缀识别与全角穿透**：
   - 识别前缀扩展支持：`-`、`－`、`task:`、`task：`、`[ ]`；
   - 匹配上述前缀时，即时激活待办模式药丸并切换占位符。
3. **安全前缀剥除防叠加**：
   - 将 Chip 点击切换时的前缀剥除正则扩展为多字符安全的：
     - `/^(@|＠|\^|＾|#|＃|!|！|\*|＊|>|》|\?|？|:|：|-|－|task:|task：|\[ \])/`；
     - 切换到其他模式或全部模式时，按匹配前缀的实际字符长度完整剥除，彻底避免产生 `-#` 或 `task:!` 叠加污染。
4. **门禁与测试**：
   - 新增 `tests/mode-chips-task-mode.test.cjs`；
   - 负向验证：若输入 `task:` 未激活待办前缀，断言必须精准红。

## 后果与影响

- 切换器多模态检索体系更完备，涵盖“页签、大纲、正文、标签、书签、命令、待办、速查”八大核心工作面；
- 兼顾单字符与语义化英文/全角前缀。
