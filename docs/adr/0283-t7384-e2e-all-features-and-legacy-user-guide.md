# ADR 0283：T-7384 端到端全功能排查、预览框全表面单例互斥与老用户功能指南 (v0.48.26)

日期：2026-10-25  
状态：accepted  
任务：T-7384  

## 背景

用户从端到端真实使用场景提出两项关键反馈与要求：
1. **“有时候第一开始打开，显示有点问题，会有两个预览框”**：
   - 在弹窗初次渲染（尤其在窗口动画或异步更新时间回填时），`scrollElement.clientWidth` 尚未完成 layout reflow 可能读取到 0，与 `useTabPreview` 的尺寸判定脱节；
   - 切换器在无搜索（`.sw__tab-preview`）与有搜索（`.sw__doc-results`）之间切换时，原清理逻辑仅针对 `scrollElement` 内，未跨整个平台表面（`surfaceScope`）执行排他互斥，导致极端异步时序下出现两个预览框并存或样式列多重留白；
2. **“另外除了页签，其他按钮不知道怎么用的。部分问题如果对老用户产生影响，要注意提供解决方式”**：
   - 老用户习惯了传统页签切换，雷切演进出的四大支柱（切换器、工作台、片段实验室、悬浮球）以及多模态穿透检索（`:`、`#`、`!`、`^`、`?`）、⌘K 动作画板、日记直达、撤销关闭等能力缺乏一目了然的低门槛引导入口；
   - 移动端触屏无法利用鼠标悬停 tooltip，导致移动端按钮功能难以发现。

## 决策

1. **`mountDocPreviewPane` 全表面单例强互斥排他防线（Global Surface Scope Singleton Invariant）**：
   - 增加首帧 `clientWidth` 自适应兜底：当 `scrollElement.clientWidth` 为 0 时，回退获取父级容器或视口宽度，避免首帧跳过而在后续事件中引起时序抖动；
   - 扩大单例清理范围至包含表面根节点（`surfaceScope`），挂载时强制 `.remove()` 任何非当前 `pane` 的多余预览节点；
   - 容器样式类严格互斥：清除全表面内非当前目标容器的所有 `sw--with-preview` 类；
2. **顶栏新增统一“帮助与功能指南”（❓）按钮**：
   - 在桌面端弹窗、右侧栏以及移动端顶栏工具栏全表面新增 `sw__help-guide-btn`；
   - 点击直接唤出图文并茂的“快速开始与使用指南”弹窗（`openPlatformGuide("switcher")`），全方位介绍各按钮用途、快捷键和使用技巧；
3. **空态引导卡片增设“功能与符号速查”胶囊区（`sw__empty-syntax-bar`）**：
   - 在零打开页签的空态卡片中，除了工作台和片段实验室入口，直接展示交互式功能胶囊：`:大纲`、`#标签`、`!书签`、`^正文块`、`?技巧`、`⌘K动作画板`、`↩撤销关闭`；
   - 点击任一胶囊即可自动回填前缀符号或执行对应动作，大幅降低新老用户的探索成本；
4. **老用户平滑兼容与设置保障**：
   - 所有升级不修改、不重置用户的任何既有配置（快捷键、排序偏好、悬浮球停靠几何位置、文档集、自定义片段草稿均 100% 保持原有状态）；
5. **版本号晋级（v0.48.26）**：
   - 全表面所有弹窗标题栏、中英文文档、更新日志与散列快照统一升级至 `v0.48.26`。
