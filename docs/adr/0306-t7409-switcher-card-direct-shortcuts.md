# 0306. T-7409 切换器卡片列表 ⌘D/⌘P/⌘W 直达快捷键与动作画板对齐契约

- **状态**：accepted
- **日期**：2026-10-27
- **任务**：T-7409

## 背景与上下文

在次级动作画板（⌘K）中，明确为卡片动作分配了快捷键：
- `⌘D`：收藏 / 取消收藏
- `⌘P`：置顶 / 取消置顶
- `⌘W`：关闭页签
然而此前在主切换器卡片网格聚焦状态下，用户按下 `Ctrl+D`、`Ctrl+P` 或 `Ctrl+W` 无法直接触发，用户必须先按 ⌘K 打开画板后再按键，产生了操作割裂。

## 架构决策

1. **卡片列表快捷键对齐支持**：
   - 在 `src/index.ts` 与 `src/index.js` 的 `bindKeydown` 中：
     - 当焦点处于卡片网格（`focusIndex >= 0`）且捕获到修饰键组合时：
       - `⌘D` / `Ctrl+D`：即时切换当前卡片收藏状态并同步顶栏下拉；
       - `⌘P` / `Ctrl+P`：即时切换当前卡片置顶状态并前置卡片；
       - `⌘W` / `Ctrl+W`：安全执行 `onCloseTab` 关闭当前聚焦页签。
2. **门禁与测试**：
   - 新增 `tests/switcher-card-direct-shortcuts.test.cjs`；
   - 负向验证：若未拦截修饰键组合直接泄露给浏览器引发默认书签/打印窗口，断言必须精准红。

## 后果与影响

- 彻底拉平动作画板与主切换器卡片列表的快捷键心智；
- 极大提升键盘流高频操作效率。
