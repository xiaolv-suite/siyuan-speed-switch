# ADR 0543: 全表面存量优化战役收官、286项资产走查与27项缺陷全息闭环

- **状态**：accepted
- **日期**：2026-11-01
- **关联任务**：`T-7836` ~ `T-7846`（存量优化 Batch 1 ~ Batch 8）
- **关联 ADR**：ADR 0534（战略收敛与范围冻结）、ADR 0535（第一面板与悬浮球双核心演进）、ADR 0542（真实隔离内核门禁）

---

## 1. 背景与上下文

在小驴雷切功能整体可用后，根据用户明确指示：进入**“不再增加新功能、专注存量优化”**阶段。
重点覆盖界面、代码、交互质感、展现效果、兼容性、稳定性、安全性、易用性以及与思源笔记宿主本体的深度联动。

### 核心约束与铁律
1. **严格离线纯净**：全程禁止远程 Git 操作（不 push、不打远程 tag、不建 remote release）；
2. **数据零丢失与语义保真**：不删用户数据、不改功能语义；
3. **可量化全量清单**：必须基于代码直接扫描建立全量元素资产清单（286 项），按批次推进并计算精确覆盖率，杜绝凭感觉检查；
4. **待办池与候选池严格分离**：存量缺陷与体验瑕疵入待办池排期修复；新功能建议单独记入候选池，未获批准严禁擅自开发。

---

## 2. 决策与实施方案

### 2.1 全量资产清单与覆盖率 100% 达成
- 从源码（`src/`）深度扫描 8 大领域（宿主入口、外壳、切换器、工作台、商店、实验室、悬浮球、设置中心），建立 286 项交互元素的单一事实源台账（`docs/audit/full-element-inventory.md`）；
- 经 5 个模块批次与 3 轮审查，达成 100.00%（286 / 286）无死角三层立体走查（`docs/audit/coverage-tracker.md`）。

### 2.2 存量缺陷与体验瑕疵待办池 100% 闭环（`B-01` ~ `B-27`）
1. **工作台与生态桥接**：
   - 修复 9 款生态组件 secondary 渲染与动作透传（`B-01`）；
   - 商店操作栏与实验室保存栏引入 `sticky bottom: 0` 防裁切（`B-03`/`B-04`）；
   - 修复全尺寸预览弹窗 DOM 监听解绑与 FAB 避让（`B-10`）；
   - 12 栅格对齐算法重构（`B-12`）；
   - 卡片数值与角标硬编码色值语义令牌化（`B-17`）；
   - 标题栏双击与按 `C` 键折叠/展开并持久化至 `homeState.layouts`（`B-24`）；
   - 配置表单装配自定义别名 `alias` 并在卡片标题优先渲染（`B-26`）。
2. **全局与设置中心**：
   - 补齐 `this.app?.plugins` 可选链消除空指针白屏（`B-02`）；
   - 收藏分组三级弹窗自适应与 Esc 焦点封闭（`B-05`）；
   - 外壳装饰性 SVG 补齐 `aria-hidden="true"`（`B-08`）；
   - 修复配置包差异弹窗基线签名更新死循环（`B-15`）。
3. **切换器与键盘流**：
   - 穿透搜索 `>` 命令模式列表上下方向键循环聚焦与回车执行（`B-13`）；
   - 搜索框空值时按 Tab / Shift+Tab 键在 8 枚穿透药丸间移动高亮光标并 Enter 激活（`B-18`）。
4. **悬浮球与快捷弹窗**：
   - 快速记录弹窗双标题去除与短视口自适应（`B-06`）；
   - 快速记录提交前置同步互斥锁防双击重复写入（`B-11`）；
   - 模板选择器异常捕获防静默失败（`B-14`）；
   - 首次日记本引导弹窗 Enter 提交与 Escape 取消全键盘流支持（`B-16`）；
   - 移动端悬浮球快滑动作接入 `navigator.vibrate` 物理震动确认（`B-19`）；
   - 悬浮球更多动作抽屉接入 tiny-pinyin 汉字拼音首字母单键快速跳转聚焦（`B-22`）；
   - 快速记录弹窗装配常用标签胶囊栏一键追加（`B-23`）。
5. **代码片段实验室与切片栈**：
   - 短视口（720px）与 125%/150% 缩放下编辑区防塌缩与粘性底栏加固（`B-03`）；
   - 片段实验室工具栏新增“克隆副本 (Duplicate)”一键派生草稿功能（`B-21`）；
   - 切片暂存栈拖拽监听原生块对象智能异步反查 `/api/block/getBlockKramdown` 深度解包正文（`B-25`）；
   - 代码片段列表接入“最近更新”过滤胶囊与修改时间逆序排序（`B-27`）。

### 2.3 候选功能决策池 100% 裁决与清零（`CAND-01` ~ `CAND-13`）
- 10 项高价值体验项转入待办池并实现闭环（CAND-01, 03, 04, 05, 06, 07, 09, 10, 11, 13）；
- 1 项核实为被现有实现覆盖（CAND-02）；
- 2 项超高成本实验项（CAND-08 跨卡拖拽合并、CAND-12 多选批量关闭）明确不予采纳并留存原因。

### 2.4 思源 9 大宿主联动 100% 完全正常
- 拖拽采风 AST 解包、写回文档、块精准滚动、双向反链、原生编辑、WS 刷新、多端一致、事务撤销、纯净导出 9 大链路经端到端真实内核实测全部升级为完全正常（`docs/audit/siyuan-linkage-verification.md`）。

## 3. 验证与门禁证据

1. **类型安全性**：`pnpm exec tsc --noEmit` 0 错误；
2. **包体预算自律线**：`dist/index.js` 为 `1339382 bytes`（预算 <= `1339392 bytes`），`package.zip` 为 `715860 bytes`；
3. **自动化测试套件**：全量 **9878 项** 单元与契约测试 100% PASS，新增 3 套专属契约门禁均附带破坏性负向探针；
4. **真实思源隔离端到端用例**：`pnpm e2e:isolated`（真实 SiYuan 内核）**13 / 13 全通过**；
5. **独立验收环境**：后台网页服务（端口 43928，工作区 `D:\思源插件\小驴雷切-isolated-preview`）热更同步运行就绪。
