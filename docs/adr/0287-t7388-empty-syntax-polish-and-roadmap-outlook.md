# ADR 0287：T-7388 空态速查胶囊栏微质感美化、片段复制悬浮动效与后续开发路线梳理 (v0.48.30)

日期：2026-10-27  
状态：accepted  
任务：T-7388  

## 背景

用户提出：“继续优化美化页面，修复 bug，全方位排查功能与逻辑，并梳理后续开发计划。”
在完成 T-7386 与 T-7387 的批量关闭矩阵与片段一键复制后，进一步针对界面的视觉微质感与后续规划展开深度推进：
1. **切换器空态速查胶囊栏美学微调**：
   - 切换器在零打开页签时的速查胶囊栏 `.sw__empty-syntax-bar`，原先样式偏素；需要注入毛玻璃半透明圆角药丸胶囊、悬浮微微抬升与细腻的主色焦点环；
2. **片段实验室列表复制按钮微动效**：
   - 新增的 `sw-studio__library-copy` 按钮需要与整体质感对齐，补齐 hover 悬浮微放大（`scale(1.05)`）与 active 点击阻尼感（`scale(0.95)`）；
3. **后续开发规划与演进路线（Post-v0.48 / v0.49+）**：
   - 全方位梳理当期账本与路线图，锚定下一阶段的三大战略方向：
     1. **多模态智能上下文工作台（Context-Aware Cockpit）**：依据活跃编辑笔记自动拉取相关联的闪卡复习、日程待办与打卡习惯；
     2. **桌面端多窗口独立置顶预览与物理硬件拓展**；
     3. **小驴生态组件与片段市场安全开放**。

## 决策

1. **空态速查栏注入微质感美学规则**：
   - 在 `src/styles/_11-ui-polish.scss` 中补充 `.sw__empty-syntax-bar` 与 `.sw__empty-syntax-chip` 样式体系；
2. **片段复制按钮注入动效微质感**：
   - 在 `src/styles/_snippet-studio.scss` 中完善 `&__library-copy` 交互反馈；
3. **后续开发演进路线确立**：
   - 同步更新当期账本与 `ROADMAP.md`；
4. **版本号晋级（v0.48.30）**：
   - 全表面所有弹窗标题栏、中英文文档、更新日志与散列快照统一升级至 `v0.48.30`。
