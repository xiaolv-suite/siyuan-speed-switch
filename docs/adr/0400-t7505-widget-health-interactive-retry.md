# ADR 0400：第二面板工作台小组件异常状态徽标可点击重试与指针交互加固（T-7505）

## 状态

已采纳 (Accepted) - 2026-10-29

## 背景

在第二面板（工作台）中，小组件在面对网络断开、服务超时或离线缓存时会进入 `failed`、`offline` 或 `stale` 状态。此前：
1. 用户在浏览模式下遇到某个组件异常时，若想单卡刷新，必须通过右键或长按菜单点选“刷新组件”，或者必须进入全局编辑态；
2. 缺乏桌面双击就地自愈与编辑态全键盘单卡刷新快捷按键。

## 决策

1. **异常状态单元格双击极速自愈**：
   - 在 `src/second-panel-ui.ts` 与 `src/second-panel-ui.js` 中，为单元格绑定 `dblclick` 监听；
   - 当检测到单元格处于 `failed`、`offline` 或 `stale` 异常状态时，直接触发 `controller.refresh(inst.config, {force: true})`，鼠标双击即可就地重试自愈。

2. **编辑态聚焦单卡 R 键极速刷新**：
   - 在卡片 `keydown` 监听中补充 `r` / `R` 快捷键判定；
   - 键盘聚焦在单元格卡片本身时，按下 `r` 即可强制重试该单卡，无需层层调用菜单。

## 验证

- **契约测试**：`tests/widget-health-interactive-retry.test.cjs` 2/2 满分通过，验证双击状态卡片就地重试与编辑态单卡 R 键刷新；
- **负向验证**：修改按键触发判定断言注入故障，确认测试精准拦截，还原后通过。
