# ADR 0385：第二面板小组件卡片折叠态条目计数角标与键盘折叠热键加固（T-7489）

## 状态

已采纳 (Accepted) - 2026-10-29

## 背景

在第二面板（工作台）中，用户可将组件折叠以节省视口空间（T-7473 引入 `span 1` 单行压缩）。此前：
1. 折叠后卡片仅保留图标与标题，用户无法感知被折叠卡片内部是否包含未读条目或条目多寡（例如有 5 条待办还是 0 条待办）；
2. 键盘导航聚焦在卡片（`cell`）本身时，用户必须按多次 Tab 才能切到折叠按钮，缺乏直达折叠/展开的快捷热键。

## 决策

1. **折叠态紧凑条目计数角标回显**：
   - 在 `src/home-view.js` 的折叠状态分支下，当组件条目数大于 0 或包含统计值时，动态向头部注入 `.sw__home-collapsed-badge` 药丸角标；
   - 包含双语 `aria-label`（如“2 条目”），数值采用 `font-variant-numeric: tabular-nums`；
   - 展开态自动销毁，不与正常内容争夺空间。

2. **卡片焦点折叠快捷热键**：
   - 在 `src/second-panel-ui.ts` 与 `src/second-panel-ui.js` 的 `cell` 键盘监听中，新增 `Space`（空格）与中括号 `[` / `]` 热键；
   - 聚焦卡片时直接触发 `cell.querySelector(".sw__home-module-fold")?.click()`，实现极速折叠与展开。

## 验证

- **契约测试**：`tests/widget-collapsed-badge-and-keyboard.test.cjs` 2/2 满分通过，验证折叠角标渲染、展开态防误显与 TS/JS 镜像热键；
- **负向验证**：修改角标断言内容注入故障，确认测试精准拦截，还原后通过。
