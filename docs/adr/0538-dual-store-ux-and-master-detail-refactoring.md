# ADR 0538: 小组件商店与片段商店双商店主从架构与场景化导航重构（T-7831）

## 状态
已决断并实施 (Accepted)

## 背景与实测诊断
针对用户指出的“两个商店现在还是很有问题，要根据逻辑，选择最合适的方案”，对真实隔离宿主（`http://127.0.0.1:43928/stage/build/desktop/`）中的两个商店进行了 DOM 与几何级排查：

1. **第二面板「小组件商店」(Widget Store) 的五大问题**：
   - **主从宽度严重倒挂**：全屏 1440px 下左目录被锁死在 `400px` 单列窄条（72 个组件需滚十几屏），右详情却占 `1040px` 空旷区；
   - **筛选栏被截断且缺少功能场景导航**：顶部筛选药丸在窄盒内溢出截断，且只有技术维度（本机服务/需前置依赖），缺少用户真正关心的功能场景入口（日记日历、任务待办、文档导航、统计洞察等）；
   - **目录卡片噪音过大**：内置日记/日历/待办卡片普遍挂着琥珀色 `条件可用` 警告，令用户误以为组件故障；
   - **详情区三处重复说明挤压预览舞台**：`detail-head`、`detail-meta` 与 `sw-store-preview__meta` 三处重复输出“思源内置 / 不发送笔记内容”，且预览卡片无论选 `小 4×3` 还是 `宽 8×3` 都 100% 撑满千像素宽，毫无真实比例感；
   - **底部操作钮弱化**：`配置` 与 `移除组件` 退化为无边框灰字。

2. **第三面板「片段商店」(Snippet Store) 的五大问题**：
   - **树形分组与商店混排造成右半列空白塌陷**：`openPicker(true)` 沿用了个人分组的 `tree` 视图，将全部内置预设塞入一个 `<section class="sw-studio__group--ungrouped">`（`未分组 (60)`）；因 `.sw-studio__group` 未声明 `grid-column: 1 / -1`，60 张卡片全部叠在左半列（`426px × 7294px`），右半列完全空白；
   - **上下堆叠把目录区压扁到 258px**：上目录 + 下预览垂直堆叠，导致目录区仅剩 258px 高（只能露出一张半卡片）；
   - **打开商店默认空白且提示生硬**：未自动选中首个预设，底部默认显示空白框与“社区目录尚未建立”；
   - **分类深藏在 `<select>` 下拉框中**：46 款覆盖 12 大分类的思源美化片段无法一眼按分类浏览；
   - **缺少一键安装启用闭环**：只有“以此新建禁用草稿”，缺少直接安装并启用到思源的主操作。

## 决策与实现（T-7831）
1. **重构「小组件商店」**：
   - **均衡双列画廊**：桌面宽屏（`>=1080px`）主从比例调整为 `52% : 48%`，左侧目录升级为双列 Bento 卡片画廊，筛选栏自动换行零截断；
   - **新增场景分类快跳胶囊栏 (`.sw-home-store__category-nav`)**：提供 `全部`、`日记与日历`、`任务与执行`、`文档与导航`、`统计与进展`、`学习与记忆`、`生活与资讯`、`系统与服务`、`小驴打卡`、`生态扩展` 场景药丸，点击即按场景过滤并自动预览首项；
   - **目录减噪与真实比例预览舞台**：收起目录行的 `条件可用` 噪音标签；右侧详情区按“标题 → 真实比例 Bento 预览舞台（随 `小 4×3 / 方 4×4 / 宽 8×3 / 大 8×5` 动态缩放宽度与多彩主题色）→ 紧凑操作吧（带清晰描边的配置/移除胶囊）→ 底部双列技术规格卡”重排视觉重心。

2. **重构「片段商店」**：
   - **宽屏左右主从双栏架构 (`.sw-studio__picker-sheet--store` + `.sw-studio__store-body`)**：商店模式升级为 `1240×820` 左右双栏（左 56% 双列卡片画廊 + 右 44% 实时渲染预览与代码透视台），目录可视高度从 `258px` 提升至 `634px`；
   - **彻底剥离树形分组干扰**：商店模式隐藏“分组视图/新建分组”，直接平铺双列卡片；同时为 `.sw-studio__group` 补齐 `grid-column: 1 / -1` 与内部双列网格，彻底修复左半列 7294px 塌陷；
   - **新增分类胶囊导航栏 (`.sw-studio__category-pills`) 与左侧探索引导卡 (`.sw-studio__library-store-cta`)**：直观展示排版、表格、代码、引用块、图片、标题、列表、标签、主题、布局等带计数胶囊；
   - **开箱自动预览 + 「⚡ 一键安装并启用」闭环**：打开商店即自动渲染第 1 款精选片段的沙箱效果与代码；新增 `⚡ 一键安装并启用` 主按钮（已安装则显示 `✓ 已在思源启用（点击停用）`），并保留 `以此新建禁用草稿` 次按钮。
