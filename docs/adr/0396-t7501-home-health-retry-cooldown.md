# ADR 0396：第二面板工作台组件卡片重试冷却保护与局部微光骨架动效加固（T-7501）

## 状态

已采纳 (Accepted) - 2026-10-29

## 背景

在第二面板（工作台）健康监控详情中，提供了一键全部重试（`.sw-home-health__retry-all`）以批量唤醒所有处于 `failed` 或 `stale` 状态的组件控制器。此前：
1. 点击“全部重试”后按钮保持可点击状态，用户在面对较慢的网络请求时容易连续狂点，导致瞬间并发多次发起网络/本地刷新，增加宿主与端点负担；
2. 缺乏防抖冷却保护与友好的秒级倒计时交互反馈。

## 决策

1. **一键全部重试 3 秒防频与秒级倒计时回显**：
   - 在 `src/second-panel-ui.ts` 与 `src/second-panel-ui.js` 中，点击重试按钮时立即设置 `disabled = true` 与 `aria-disabled="true"`；
   - 启动 3 秒循环定时器，动态更新按钮文字为 `全部重试 (3s)`、`全部重试 (2s)`、`全部重试 (1s)`；
   - 3 秒倒计时结束后平滑解除禁用并恢复原始文案，若弹窗已销毁自动注销定时器。

2. **样式层骨架微光与状态联动**：
   - 在 `src/styles/_05-settings-widgets.scss` 中保持 `@keyframes sw-home-skeleton-pulse` 稳健运行，并配合 `aria-disabled` 降低高频重击风险。

## 验证

- **契约测试**：`tests/home-health-retry-cooldown.test.cjs` 满分通过，验证 TS/JS 镜像禁用状态、秒级回显与倒计时恢复；
- **负向验证**：修改倒计时格式断言注入故障，确认测试精准拦截，还原后通过。
