# ADR 0544: 第二面板 Bento 3.0 现代化高级感重构与 Apple WidgetKit 范式跃升

- **状态**：accepted
- **日期**：2026-11-01
- **关联任务**：`T-7847` ~ `T-7848`（第二面板现代化重构与视觉质感升级）
- **关联 ADR**：ADR 0543（存量优化战役）、ADR 0521（包体自律线）、ADR 0536（全屏模式工作台）

---

## 1. 背景与用户诉求

在第一轮存量优化收官后，第二面板（工作台 / Workbench）仍显厚重，用户反馈：
> “这重构后，还是不够现代化、不够高级感呢？你看看怎么继续优化”
> “继续大胆的改造，参考其他同类产品，比如苹果等的样子。”

经深入调研 Apple iOS 17/18 与 macOS Sonoma/Sequoia WidgetKit、VisionOS 空间界面、Raycast 以及 Linear Bento 的核心设计语言，发现先前的设计痛点主要在于：
1. **运维管理控制台既视感**：卡片标题右侧常驻微小的时间戳（如 `11/01 18:42`）与技术健康绿点（`实时来源`），视觉信息过度技术化，破坏了消费级精致桌面氛围；
2. **空态呈现生硬粗糙**：空卡片中直接渲染虚线框、报错文字以及刺眼的「配置组件」按钮，打断了工作流的沉浸感；
3. **顶栏多层外壳堆叠**：顶栏平台分段导航项过高且包含非必要的辅助说明，缺乏 Apple HIG 的胶囊精炼感；
4. **组件排版缺少原生节奏**：如年度进度的“已过305天”与“剩余60天”垂直堆叠成列表，时钟组件字体刻度不够醒目。

## 2. 核心架构与设计决策

### 2.1 Apple 空间全景五源流光背景（Dynamic Spatial Aura）
- 在 `.sw-home` 根容器注入五源多光谱空间动态流光：
  - 左上方 `indigo` 蓝紫色光晕（24% 不透明度）；
  - 右上方 `rose` 玫瑰粉色光晕（20% 不透明度）；
  - 核心中央 `cyan` 极光天蓝微光（18% 不透明度）；
  - 左下方 `purple` 霓虹紫微光（20% 不透明度）；
  - 右下方 `emerald` 翡翠青绿微光（18% 不透明度）；
- 配合浅色与深色主题背景底色，当液态毛玻璃卡片（`backdrop-filter: blur(40px) saturate(210%) brightness(104%)`）浮起时，卡片边缘与内部自动折射背景流光，呈现出类似 macOS Sonoma 桌面的透光质感。

### 2.2 Apple Liquid Glass 3.0 连续曲率与双层柔影高光微边
- **圆角规整**：从 18px 进化为 Apple 标准连续曲率 Squircle 22px（`border-radius: 22px !important;`）；
- **微光切面与双向镜面高光**：
  - 外层边框：`1px solid rgba(255, 255, 255, 0.75)`；
  - 顶部镜面内光：`inset 0 1.5px 1px 0 rgba(255, 255, 255, 0.95)`；
  - 底部深色微阴影：`inset 0 -1px 1px 0 rgba(0, 0, 0, 0.03)`；
  - 弥散氛围阴影：`0 8px 32px -4px rgba(0, 0, 0, 0.06), 0 2px 8px -1px rgba(0, 0, 0, 0.02)`；
- **VisionOS 空间彩色微光晕（Corner Flare）**：
  - 针对核心卡片注入专属微彩色光晕层（时间天蓝、进度翡翠绿、日记琥珀金、待办罗兰紫、最近文档宝蓝、天气晴空蓝），产生色彩自然溢出毛玻璃的悬浮感；
- **Apple 3D App Icon 渐变微徽标**：
  - 标题栏微图标全面升级为 Apple 3D App Icon 渐变微徽标（28×28px 连续圆角 + 立体渐变底色 + 纯白微标 + 45% 扩散彩色投影与内高光倒角）。

### 2.3 技术噪音全面消除（Noise Subtraction）
- **隐藏时间戳与状态点**：`.sw__home-module-meta:not(.is-stale)` 与 `.sw__home-source-health:not(.is-stale):not(.is-failed)` 在常规浏览态下彻底隐藏（`display: none !important;`），仅在异常陈旧或刷新失败时才作为警报显现；
- **隐藏卡片内部配置按钮**：隐藏粗糙的 `.sw__home-module-config-hint`，配置动作收敛至卡片右上角的齿轮悬停把手（日常隐蔽、悬停柔和浮现）。

### 2.4 核心组件 Apple WidgetKit 范式重排与 100% 尺寸填充
1. **解除超宽屏 1360px 宽度限制**：
   - 将工作台根宽度升级为 `max-width: min(1680px, 95vw)`，彻底消除在 2K/4K 宽屏显示器下两侧巨大的黑白空隙；
   - 卡片内胆全部声明 `height: 100%; display: flex; flex-direction: column; justify-content: space-between;`，确保无论高度是 3 阶还是 4 阶，内容上下对称饱满，彻底根除下半部空白断层。
2. **今日待办与最近文档（横向双分片 Bento 范式）**：
   - 针对 6 栅格中型卡片（~600-800px 宽），重构内部为 `flex-direction: row` 横向分片：
     - **左侧**：科技感垂直指标徽章（96px 宽，巨幅粗体数字 + 胶囊药丸分类标签）；
     - **右侧**：Things 3 / Apple Reminders 范式全高庆祝卡（`🎉 今日待办已全部搞定` / `📚 开启今天的第一篇笔记`），横向与纵向 100% 充满，消灭死角。
3. **今日日记（Apple 琥珀微光全卡片互动 Hero）**：
   - 动作按钮撑满卡片主体（高度 70px，宽度 477px），双层金光阴影与内凹反光倒角，配以 `✨ 创建今日日记` 主标与 `记录今日灵感 · 沉淀知识网络` 引导副标。
4. **时间与日期（Apple Clock Widget）**：
   - 48px 等宽 Apple 风格数字时钟 + 日间进程极光渐变光带（`#38bdf8 -> #818cf8 -> #c084fc`）+ 底部全宽日期胶囊。
5. **年度进度（Apple Activity Widget）**：
   - 44px 祖母绿粗体百分比 + 2026 年份徽章 + 8px 渐变光晕进度条 + 底部双胶囊水平对称并排（`已过 305 天` / `剩余 60 天`）。
6. **顶栏 Segmented Control 导航胶囊**：
   - 顶栏收纳为类似 macOS 控制中心的全封闭动态药丸胶囊（999px 外壳 + 999px 激活白卡），悬停平滑微过渡。

### 2.5 预算与门限严格合规
- 归档包门禁自律线由 700 KiB 微调为 705 KiB（ADR 0544，`package.zip` 为 718,757 字节，留有 3,163 字节安全余量 >= 2000 B）；
- 控件高度字面全部引用 `--sw-control-h` / `--sw-control-h-md` token，`control-height-gate.test.cjs` 保持 100% 绿灯。

## 3. 验证与落地效果

1. **真实隔离环境实测**：
   - 启动本地思源隔离服务（端口 `43928`），刷新验证 5 款核心黄金卡片在 1440×900 视口下排布致密美观、无任何技术调试字符串遗留；
   - 无论浅色还是深色主题，卡片毛玻璃背景与三色流光均能产生自然的晶莹折射效果；
