# 0308. T-7411 工作台组件健康监控「一键全部重试」自愈把手契约

- **状态**：accepted
- **日期**：2026-10-27
- **任务**：T-7411

## 背景与上下文

在工作台小组件健康详情监控（`openHomeHealthDetails`）弹窗中，当出现多个小组件因网络波动或外部插件启动迟滞而呈现失败状态时，此前用户必须逐一点击每一个失败项的“重试”按钮，操作繁琐且缺乏批量自愈能力。

## 架构决策

1. **批量重试把手注入**：
   - 在 `src/second-panel-ui.ts` 与 `src/second-panel-ui.js` 的 `renderHealthList` 中：
     - 检测当前组件列表中是否存在非 `ok` 的异常组件；
     - 若存在且设置未禁用重试（`retryFailed !== false`），在底部操作栏装配 `.sw-home-health__retry-all`（“全部重试”）按钮；
     - 点击后批量触发所有失败项的 `controller.refresh(undefined, {force: true})`，并带防重与在途锁控制，完成后自动重绘健康列表。
2. **门禁与测试**：
   - 新增 `tests/home-health-retry-all.test.cjs`；
   - 负向验证：若无失败项时渲染全部重试按钮，断言必须精准红。

## 后果与影响

- 极大提升多组件异常场景下的一键批量自愈效率；
- 遵循防重击与在途状态锁机制，保障系统平稳。
