# 架构决策记录 0481：T-7605 视觉与感知层现代质感升级、设计令牌收敛与内阴影重描边清零

- **状态**：accepted
- **日期**：2026-10-29
- **任务**：T-7605
- **参与者**：小驴开发团队、自动化视觉门禁体系

---

## 一、 背景与动因

在小驴雷切多表面演进历程中，样式层沉淀了大量从早期桌面弹窗、侧栏到移动端 Sheet 的样式规则。在经过深广审计后，发现感知层存在少量违背现代工业级科技质感规范的遗留问题：
1. **残存内阴影 (Inset Shadow)**：`_02-settings.scss` 中的设置舞台区域残存 `box-shadow: inset 0 1px 5px rgba(35, 42, 75, .07);`，破坏了平整微抬升的现代表面感；
2. **多重描边与重边框**：开关控件存在 `border: 1px solid` 与 `box-shadow: inset 0 0 0 1px` 双重边框叠加；
3. **杂乱硬编码渐变与色值**：部分小组件与日夜指示存在硬编码高饱和渐变（如 `#ffd54f`, `#6252c6`），脱离了宿主主题的动态自适应体系；
4. **数字跳变抖动**：部分时钟、统计和进度条副文本未声明等宽排版，数据跳变时存在横向像素微晃；
5. **高分屏基线偏差**：设置项行容器因绝对微调在 Windows 125%/150% 缩放下存在 1~2px 垂直物理错位。

---

## 二、 核心决策与改造分级

本轮视觉改造严格遵循分级改造策略：**默认走最低 A 档（只改样式不动结构），严禁删除已有功能与破坏数据契约**。

### 1. A 档主体改造（95% 范围）
- **令牌基线收敛**：在 `_00-tokens.scss` 确立等宽字体 `--sw-font-mono`、触控区 `--sw-touch-target: 44px` 以及动态派生的 `--sw-color-accent/surface/line/text/success/warning/error` 语义体系；
- **过时视觉痕迹清除**：彻底铲除内凹阴影、多重描边，将硬编码渐变转换为基于宿主主色与语义色的 `color-mix` 漫反射；
- **光影与焦点收敛**：统一绑定三档蓝灰正向阴影（`--sw-shadow-xs/sm/md`）与双层自适应微光焦点环（`--sw-focus-glow`）；
- **精密数字等宽化**：对所有计时器、待办统计与小组件数据全量注入 `font-variant-numeric: tabular-nums`。

### 2. B 档极局部微调（仅 1 处）
- **设置项行容器对齐**：针对 `.sw-settings__item`，确立 `min-height: 48px;` 与现代弹性对齐（`display: flex; align-items: center; justify-content: space-between;`），确保在不同 DPI 与缩放比例下标题基线与右侧控件中心严格居中对齐。DOM 结构、字段名与无障碍属性保持 100% 不变。

### 3. C 档推翻重做
- **本轮无 C 档**。所有面板的信息架构与状态流转均成熟稳固，严禁进行破坏性大重构。


- **负向验证**：向 `_02-settings.scss` 故意注入该内凹阴影后，门禁测试精准报错（Exit Code 1），拦截证据完整；
- **浏览器实测**：真实 Chromium 样式冒烟测试（Dark/Light 双主题）全绿，正文与大字对比度均显著超越 WCAG AA 4.5:1 / 3:1 标准。
