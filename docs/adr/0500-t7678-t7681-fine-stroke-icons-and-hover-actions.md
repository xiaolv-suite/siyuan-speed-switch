## 一、 背景与动因

在视觉与感知层规范落地中，针对图标系统风格与列表行尾操作的感知秩序，发现了以下两处细节优化点：
1. **SVG 矢量图标端点风格不一**：部分图标线宽和端点未统一声明圆润连接，高分屏下容易呈现机械生硬感；
2. **列表行尾操作过于喧宾夺主**：卡片右侧的置顶图钉、星标收藏与关闭按钮在非悬停状态下若高亮全显，会导致长列表中右侧视觉权重过重，破坏主标题与元信息的阅读主次；
3. **深色模式下悬停分界微弱**：在深色钛黑底色下，卡片悬停需要更深邃、通透的 1px 微反光切边（`--sw-rim-light`）。

---

## 二、 架构决策与标准落地

### 1. T-7678 细线风格图标圆角端点全量统一（A 档）
- `src/styles/_11-ui-polish.scss`：
  - 为全平台作用域（`.speed-switch, .sw-home, .sw-studio, .sw-fab-root`）统一注入 `svg { stroke-linecap: round; stroke-linejoin: round; }`；
  - 保证所有矢量图标端点圆润、线条连接平滑，完全消除生硬的 butt 直角截断。

### 2. T-7679 卡片行尾操作按钮常态轻隐与悬停完全浮现（A 档）
- `.sw__card .sw__pin`, `.sw__card .sw__fav-btn`, `.sw__card .sw__close`：
  - 常态下声明 `opacity: 0.72;`，降低视觉噪音，让用户的视线自然聚焦于文档标题与路径；
  - 在卡片处于 `:hover` 或 `:focus-within` 时，平滑过渡至 `opacity: 1;` 并响应微缩放微触感，实现操作与阅读的平衡。

### 3. T-7680 深色模式悬停光影微差与对比度强化（A 档）
- 保持 `--sw-rim-light` 1px 金属微反光在深色悬停态稳定呈现。

### 4. T-7681 专项契约测试与破坏性负向探针验证
- 新增专项测试 `tests/fine-stroke-icons-and-hover-actions-contract.test.cjs`；
- 破坏性负向探针验证图标线端若被破坏为 butt 直角截断必报错。
