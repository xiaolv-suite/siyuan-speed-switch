# 0292. T-7395 工作台「渐进知识蒸馏漏斗 (knowledge-funnel)」Bento 组件契约

- **状态**：accepted
- **日期**：2026-10-27
- **任务**：T-7395（关联 Issue #17 中枢深化第二期建议）

## 背景与上下文

在快门中枢统领的渐进学习体系中，用户的知识流动包含三部曲：
1. **输入与收集**：稍后读与长文分片（由小驴拾遗管理）；
2. **提炼与整理**：高频词条、摘录与关键片段（由思源原生或小驴常用管理）；
3. **内化与记忆**：间隔复习与记忆闪卡（由小驴闪卡管理）。

为了让用户在雷切第二面板（工作台）对个人知识体系的消化吞吐量一目了然，需在小组件商店中新增标准的 `knowledge-funnel`（渐进知识蒸馏漏斗）Bento 双拼瓦片小组件。

## 架构决策

1. **组件注册与元数据**：
   - 在 `src/home-external-adapters.ts`（及对应编译产物）注册 `knowledge-funnel`；
   - 来源归属于小驴生态（`pluginId: "siyuan-glean"`, 集合 `Ecosystem`）；
   - 双语 i18n 注入 `homeKnowledgeFunnel`（渐进知识蒸馏漏斗）与 `homeDescKnowledgeFunnel`（待读分片 ➔ 待提炼摘录 ➔ 今日到期闪卡全库吞吐量）。
2. **多源数据联邦聚合**：
   - **待读分片**：安全读取 `glean.listClips({status: "later"})` 与 `{status: "reading"}` 数量；
   - **待提炼摘录**：安全读取 `common.recent()` 或笔记常用摘录；
   - **今日到期卡**：安全读取 `cards.getDueSummary()` 中 `unreviewedCount`；
   - 聚合为 Bento 双拼卡片，展示 3 阶段流转吞吐量，主指标显示全库总流转量。
3. **单向异常隔离与 800ms 熔断**：
   - 外部调用全部经由 `wrapEcosystemModuleRead` 包装；
   - 兄弟插件任一不可达或超时，该项数值归零，不阻断其他数据项渲染；
   - 插件全部缺失时展示友好指引空态。
4. **门禁与测试**：
   - 新增 `tests/knowledge-funnel-widget-contract.test.cjs` 验证注册、字段、多数据源组合与降级容错；
   - 负向验证：若任一外部桥抛错，确认漏斗组件安全返回而不拖垮工作台渲染。

## 后果与影响

- 全景打通雷切工作台与拾遗、闪卡等兄弟插件的数据协同，丰富 Bento 瓦片生态价值；
- 遵循零强依赖与 800ms 熔断，保障工作台在大库与离线场景下的稳定表现。
