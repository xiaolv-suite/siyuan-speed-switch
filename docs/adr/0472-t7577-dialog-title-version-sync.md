# ADR 0472：全表面 18 处二级弹窗品牌版本徽标统一递增至 v0.48.83（T-7577）

## 状态

已采纳 (Accepted) - 2026-10-29

## 背景

伴随全面质量优化战役（T-7565 ~ T-7576：动态加载容灾、弹窗析构守卫、FAB 避让、inert 锁死防御、回流与布局抖动消除、实时防抖、键盘陷阱消除、主切换器 Home/End/Page/Space 漫游、移动端 44px 热区与手势隔离、通用模态焦点捕获循环等）相继落地闭环，全表面 18 处二级弹窗标题栏的版本胶囊需统一递增对齐至 `v0.48.83`，消除版本号孤岛与界面割裂感。

## 决策

统一升级以下 18 处二级弹窗的 `mountPlatformDialogTitleWrap` 版本标记至 `v0.48.83`：
1. `doc-search-ui.ts` / `.js`：编辑保存的搜索弹窗；
2. `home-config-form.ts` / `.js`：小组件配置表单弹窗；
3. `home-store-ui.ts` / `.js`：小组件商店主弹窗与内联预览弹窗；
4. `index.ts` / `.js`：快速指南、系统设置、主切换器、移动端切换器与片段实验室主弹窗；
5. `second-panel-ui.ts` / `.js`：工作台主弹窗与小组件健康监控弹窗；
6. `settings-sections.ts` / `.js`：文档集版本差异对比弹窗与配置包差异对比弹窗；
7. `snippet-studio-ui.js`：Gist 恢复、草稿离开确认、版本冲突对比、备份还原预览与片段导入方案弹窗。

## 验证

- **契约测试**：`tests/dialog-title-version-sync.test.cjs` 2/2 满分通过，验证全工程 18 处调用 100% 精确对齐 `v0.48.83` 且无旧版本残留。
