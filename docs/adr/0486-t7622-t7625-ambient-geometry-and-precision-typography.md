# 架构决策记录 0486：T-7622~T-7625 情感化几何微点缀、数据列等宽右对齐与舒适阅读行高收敛

- **状态**：accepted
- **日期**：2026-10-29
- **任务**：T-7622, T-7623, T-7624, T-7625
- **参与者**：小驴开发团队、视觉感知与精密排版治理

---

## 一、 背景与动因

在完成两色分工与 Bento 双层柔影后，进一步对标参考图中的图形表达与排版细节精度，发现三处微质感提升空间：
1. **空状态生硬冰冷**：切换器无结果与空态提示仅显示单薄文本或实线框，缺乏有体积感、情感化的视觉呼吸；
2. **统计数据列基线漂移**：小组件列表项中的次级数值未强制右对齐，在不同文字长度下数据起始基线参差不齐，缺乏数据报表的秩序美；
3. **中文排版行高与字重发散**：多行正文行高此前为 1.6，略微紧缩；存在 620、740、750 等历史散落字重，违背“中文字重只用常规(400)、中黑(500)、半粗(600)三档”的规范。

---

## 二、 架构决策与标准落地

### 1. T-7622 空状态情感化几何微色块点缀（A 档）
- 依据参考图图形表达规律，为 `.sw__empty` 注入 36×36px 纯 CSS 圆润微徽章；
- 严格限制颜色仅取主题色的三档明度（10% 底色、24% 微光、48% 聚光径向球），以微体积感带来温暖陪伴，面积小且固定，不干扰任何真实信息读取。

### 2. T-7623 数据统计列等宽数字右对齐（A 档）
- 对小组件列表次级数值 `.sw__home-module-item-secondary`、活动统计值 `.p-activity-total` 明确声明 `text-align: right` 与 `font-variant-numeric: tabular-nums`；
- 形成左侧标签左对齐、右侧数据右对齐的严谨工业级基线。

### 3. T-7624 中文排版行高 1.65 与三档字重收敛（A 档）
- 将多行段落行高 `--sw-leading-reading` 锁定为 1.65（落在 1.6~1.75 舒适中文阅读黄金区间）；
- 清除 620、740、750 等非常规字重，全面归并至 `--sw-weight-medium (500)` 与 `--sw-weight-semibold (600)`。

### 4. T-7625 契约测试与破坏性负向探针验证
- 新增专项测试 `tests/ambient-geometry-and-precision-typography-contract.test.cjs`；
- 验证微点缀面积超标（如 >60px）或数据列失真必精准报错。
