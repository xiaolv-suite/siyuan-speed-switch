# 0300. T-7403 多模态搜索模式 Chips 栏全角符号识别与切换防重叠契约

- **状态**：accepted
- **日期**：2026-10-27
- **任务**：T-7403

## 背景与上下文

在切换器多模态搜索模式 Chips 药丸栏（`sw__mode-chips-bar`）中，用户可以通过输入对应的前缀符号触发不同模式的即时搜索（`@` 标题大纲、`^` 正文块、`#` 标签、`!` 书签、`>` 命令、`?` 速查）。
但此前在 `setupSearchModeChips` 的 `updateActiveMode` 中，仅匹配了半角英文符号（如 `@`, `#`, `^`），未考虑中文输入法下用户自然键入全角符号（`＠`、`＃`、`＾`、`＊`、`……`）的场景，导致输入了全角符号但 Chips 栏未点亮激活态；此外，在点击另一个 Chip 时，旧前缀剥除正则遗漏全角字符，导致出现 `!＃项目` 双前缀叠加的检索错误。

## 架构决策

1. **全角穿透符号全量识别**：
   - 在 `setupSearchModeChips` 的 `updateActiveMode` 中扩展符号前缀判定：
     - 大纲模式：支持 `@`、`＠`、`:`、`：`；
     - 正文块模式：支持 `^`、`＾`、`……`；
     - 标签模式：支持 `#`、`＃`；
     - 书签模式：支持 `!`、`！`、`*`、`＊`；
     - 命令模式：支持 `>`、`》`；
     - 速查模式：支持 `?`、`？`。
2. **前缀剥除安全正则对齐**：
   - 将 Chip 点击切换时的前缀剥除正则对齐升级为 `/^[@＠^＾#＃!！*＊>?？》:：]/`，彻底避免双前缀污染。
3. **门禁与测试**：
   - 新增 `tests/mode-chips-fullwidth-symbol-sync.test.cjs`；
   - 负向验证：若输入全角 `＃` 无法点亮标签模式或切换产生双前缀，断言必须精准红。

## 后果与影响

- 中文输入法用户在使用大纲、正文、标签、书签检索时体验高度丝滑自然；
- 彻底消除多模态切换时的前缀字符污染。
