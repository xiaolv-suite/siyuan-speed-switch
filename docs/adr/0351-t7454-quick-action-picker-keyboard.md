# 0351. T-7454 快捷动作选择器 Escape 退出、搜索框全选与键盘流加固契约

- **状态**：accepted
- **日期**：2026-10-28
- **任务**：T-7454

## 背景与上下文

在设置中心配置快捷动作时，点击添加或替换会弹出快捷动作选择下拉列表（`mountQuickActionPicker`）。
此前该浮层未监听 `Escape` 键，用户无法按 Escape 快速关闭；搜索框获焦时未自动全选；按 `ArrowDown` 无法从搜索框直达列表项；在动作项间也缺少方向键循环导航与首项按 `ArrowUp` 回焦搜索框。

## 架构决策

1. **Escape 阶梯退出与回焦恢复**：
   - 当焦点在搜索框且有内容时，按 `Escape` 先清空输入并重绘列表；
   - 当无输入或在结果列表时按 `Escape`，销毁选择器并将焦点安全归还至原触发按钮（`trigger.focus()`）。
2. **搜索框至列表的双向键盘流**：
   - 搜索框绑定 `focus` 自动 `select()`；
   - 搜索框按 `ArrowDown` 直达列表首个可用动作，按 `Enter` 直接执行首项；
   - 列表首项按 `ArrowUp` 逆向回焦搜索框。
3. **列表项循环流与 Home/End 支持**：
   - 列表项支持 `ArrowDown` / `ArrowUp` 平滑循环流转；
   - 支持 `Home` 与 `End` 直达首末项动作。
4. **门禁与测试**：
   - 新增 `tests/quick-action-picker-keyboard.test.cjs`；
   - 负向验证：若选择器未绑定 Escape 退出与回焦，断言必须精准红。

## 后果与影响

- 极大提升快捷动作选择配置界面的全键盘效率与无障碍友好度。
