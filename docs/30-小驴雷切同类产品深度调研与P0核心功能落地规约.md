# 小驴雷切 · 同类产品深度调研与 P0 核心功能落地技术规约

> **适用仓库**：`小驴雷切/` (`siyuan-speed-switch`)  
> **对标产品**：VS Code 多栏分屏与 Diff 引擎、Obsidian Workspaces 工作区预设、Heptabase 并排对照  
> **核心哲学**：让思源笔记的分栏对照从“手工笨拙拖拽”跃迁为“工业级同步比对与工作空间瞬间还原”。

---

## 一、 同类标杆比对与核心痛点穿透

| 标杆产品 | 最具杀伤力的机制 | 解决的传统痛点 | 小驴雷切吸收与创新结合点 |
| :--- | :--- | :--- | :--- |
| **VS Code** | **同步滚动锁定 (Scroll Lock)** | 左右两栏对照长文翻译或两份报告时，滚完左边滚右边，极其疲劳断流 | **双栏同步滚动锁定**：按比例或按标题锚点，左侧滚动右侧自动同频平滑同步 |
| **VS Code Diff** | **行级可视化差异对比 (Visual Diff)** | 文档修改后无法一眼看出改了哪几句话，或者两个版本找不到差异 | **文档可视化 Diff 比较视图**：左右分栏红绿高亮变更行、删除行与新增块 |
| **Obsidian Workspaces** | **工作区布局快照与一键切换** | 每天工作都要手动分栏打开“今日计划+进行中文档”，重复繁琐 | **工作空间预设 (Workspace Presets)**：一键保存/还原特定文档组合与分栏状态 |

---

## 二、 P0 级别建议加入的核心功能技术方案

### 功能 1：双文档分栏同步滚动锁定（Synchronized Scroll Lock）
- **功能逻辑**：
  - 在分栏标题栏提供【🔗 同步滚动锁定】开关；
  - 开启后，监听当前激活栏的滚动事件（`scrollTop / scrollHeight` 相对百分比）；
  - 利用 `requestAnimationFrame` 同步平滑驱动另一栏滚动，支持：
    - **相对百分比同步**（针对长短不一致的长文）；
    - **大纲标题锚点对齐**（当两篇文档包含相似章节标题时，自动对齐同名标题）。

### 功能 2：双文档内容/历史版本可视化 Diff 对比视图（Visual In-Editor Diff）
- **功能逻辑**：
  - 在分栏模式下点击【⚖️ 对比差异】；
  - 插件在本地调用快速 LCS 差分算法，提取两篇文档（或同一文档的历史快照）的块级与行级差异：
    - 绿色高亮：右侧新增块/段落；
    - 红色高亮：左侧已被删除块；
    - 灰色折叠：完全相同的冗长段落；
  - 支持“一键合并变更（Merge block from left to right）”。

### 功能 3：多文档分栏工作区布局快照与一键还原（Workspace Presets）
- **功能逻辑**：
  - 用户经常有固定搭配（例如：`左栏: 2026考研计划 + 右栏: 操作系统重点`）；
  - 提供【保存为工作空间预设】：记录左右分栏文档的 `doc_id`、分栏比例（如 50:50 或 70:30）与滚动位置；
  - 之后在雷切主窗口按快捷键或点击下拉列表，**0.1 秒瞬间恢复整套多文档分栏现场**！

## 三、 双端 UI 与全生态质量红线
1. 滚动性能：同步滚动必须加防抖与 `isProgrammaticScroll` 互斥锁，彻底杜绝左右死循环颠簸；
2. 移动端 390×844：分栏模式自动转换为“顶部 Tab 快速滑块切换”，禁止在窄屏强行双列排版。
