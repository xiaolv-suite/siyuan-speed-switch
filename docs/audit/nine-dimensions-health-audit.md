## 逐维度深度审查与加固详情

### 1. 界面质感 (D-1)
- **视觉层级与微底托盘**：全表面统一采用 Bento 双层微底规范，外层微底托盘 `--sw-bg-tinted`，内层卡片使用 `--sw-card-float-bg`（`var(--b3-theme-surface)`），阴影使用 `--sw-shadow-xs`，保证在深色、浅色及高对比度模式下层次分明。
- **长文本截断防御**：全界面 10 处核心标题与路径节点均声明 `flex: 1; min-width: 0; overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`，极端长标题（100+ 字符）绝不撑破卡片栅格。
- **系统缩放防截断**：针对 Windows 常见 125%/150% 缩放（等效高 <= 720px）以及手机软键盘顶起，代码片段实验室与工作台详情窗格均采用 `position: sticky; bottom: 0; z-index: 2` 结合独立纵向滚动，保证保存与添加等主动作首屏可见。

### 2. 图标规范 (D-2)
- **拒绝外挂感**：全工程彻底杜绝引入第三方图标库（如 react-icons、lucide、fontawesome 等），100% 复用思源笔记本体内嵌的 SVG Symbol Sheet（通过 `<use xlink:href="#iconXxx">` 挂载）。
- **主题跟随特性**：所有图标颜色优先继承父级 `color: currentColor` 或 `--b3-theme-*`，主题切换（明亮、暗黑、高对比度）时线宽、色彩完全随宿主同步流转。

### 3. 交互触感 (D-3)
- **连点防重与并发互斥**：
  - 快速记录提交函数（`src/index.ts:3272`）将锁变量 `saving = true` 以及按钮禁用提升至同步最顶层，彻底杜绝连续快速双击向文档写入重复内容的隐患（`B-11`）。
  - 组件全尺寸预览弹窗与悬浮球动作执行均设置版本时钟与排他锁。
- **可撤销性（Undoability）**：
  - 第一面板误关页签：支持 `Ctrl+Z` 瞬时恢复；
  - 第二面板工作台排版：编辑横幅提供完整的撤销/重做步进；
  - 第三面板切片栈：清空未锁定项与单项删除均提供底栏一键撤销（Undo）；
  - 设置中心：恢复默认设置均配备撤销回执条；
  - 思源文档写入：完全进入思源底层历史，在文档内按 `Ctrl+Z` 可原地撤销。

### 4. 兼容能力 (D-4)
- **宿主兼容范围**：向下兼容思源 3.8.x 系列全版本，API 调用优先采用特性探测（Feature Detection）而非生硬判定版本号。
- **存储数据升降级防护**：`src/index.ts:1700-1715` 设立 `STORAGE_SCHEMA_VERSION` 门禁。若检测到当前存储版本高于插件版本（用户降级安装旧版插件），自动保留未知字段，杜绝数据损坏与格式截断。

### 5. 系统稳定 (D-5)
- **错误沙箱与降级**：
  - 工作台 58+ 款小组件各自运行于独立渲染沙箱中，当某个组件网络超时或数据源未就绪时，仅在该卡片内呈现友好重试态，绝不引发整个面板白屏。
  - 穿透搜索 SQL 查询增加 `1200ms` 熔断超时机制，超时自动降级展示已打开标签。
- **防内存泄漏与资源释放**：
  - 全表面 Dialog 均实现 `destroyCallback`，并在销毁时显式卸载 DOM 监听、解绑全屏 ResizeObserver、清除定时器与解除悬浮球让位（`B-10`）。
  - 第一面板缩略图与标题缓存采用 `WeakMap`，随着卡片销毁自动释放内存。

### 6. 安全隐私 (D-6)
- **数据存储合规**：所有插件配置、历史记录、收藏夹与文档集均存储在思源笔记专有的沙箱存储区（`data/storage/`），绝不私自在系统临时目录或非授权磁盘区遗留散落文件。
- **防 SQL 注入**：SQL 穿透检索在 `escapeSqlLiteral` 中严格执行单引号转义并剔除危险的注释符与分号，强制追加 `LIMIT 40/200` 约束。
- **防 XSS 注入**：富文本与 HTML 解析统一走离线 `<template>` 容器，仅读取 `textContent` 提取 AST 纯文本，绝不向主文档挂载任意未过滤 HTML。

### 7. 易用体验 (D-7)
- **文案人话化**：剔除所有机械机翻或底层技术术语，全量 300+ 词条使用符合中文用户直觉的表达（如“闪念随手记”、“切片暂存栈”、“场景预设”等）。
- **指引带下一步**：所有空状态（如“无搜索结果”、“暂无收藏”、“暂存栈为空”）均提供直接可点击的按钮（如“新建笔记”、“打开今日日记”、“导入预设”）或明确快捷键指引，不把用户晾在死胡同。

### 8. 代码质量 (D-8)
- **单一 TypeScript 事实源**：彻底清除历史上 16 个冗余的同名 `.js` 镜像文件（共 2.8 万行死重代码），构建与测试 100% 直读 `.ts` 源码。
- **类型严谨与包体受控**：`tsc --noEmit` 0 错误；`dist/index.js` 与 `package.zip` 严格处于 ADR 0539/0542 体积预算自律线内。

### 9. 思源联动 (D-9)
- **深度双向互通**：支持拖拽采风、日记追加、块精准定位、反链建立、原生编辑、WebSocket 实时同步、多窗口一致性、历史记录可撤销与导出零污染，9 大核心链路经过端到端真实思源内核实测，事实证据详实确凿。
